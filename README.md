# The genetic basis for synchronised time perception in plant populations 

This repositories contains all the code required to generate the figures in the manuscript.

# System requirements
R (required): tested on R version 4.3.2 (2023-10-31 ucrt)
RStudio (recommended): 2024.12.1 Build 563
No non-standard hardware required.

# Installation

Pull the repository from Github and open the project in RStudio

# Contents

- `sync_R_analysis` contains the R scripts for every section (except the elastic net models)
- `sync_python_scripts` contains the Python scripts and Jupyter notebooks to fit and analyse the results from the elastic net models

There are more detailed READMEs in the subfolders.

# Demo
All scripts are demoed on data directly from the manuscript.  
The only file that is not provided in the repository is the VCF file, which is a large supplementary table.
The expected outputs are the figures from the paper

# Instructions

Instructions are in the sub-folders.  
Generally, each script should be run sequentially, in numerical order.
